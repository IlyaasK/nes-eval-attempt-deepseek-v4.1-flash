Provenance notes
------------------------------------------------------------------------

- The release asset was uploaded by the repository owner (wendelscardua)
  to the 0.1.0 GitHub release.
- src/music/soundtrack.txt at the tag lists the tracks "RPGBattleTheme -
  Ted Kerr", "victoryloop - Ted Kerr" and "Cave - Ted Kerr". Ted Kerr's
  OpenGameArt uploads (account Wolfgang_) with those titles list the
  license as CC0:
    https://opengameart.org/content/8-bit-rpg-battleencounter-theme (License(s): CC0; Attribution Notice: Ted Kerr)
    https://opengameart.org/content/8-bit-victory-loop (License(s): CC0)
    https://opengameart.org/content/8-bit-cave-loop (License(s): CC0)
- src/music/credits.md at this tag is a stale copy of File Fixers'
  music credits and does not describe this game's soundtrack;
  soundtrack.txt and the README above do.
