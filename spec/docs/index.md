# NES hardware reference (offline)

Offline copy of NESdev Wiki pages covering the NES/Famicom CPU (2A03 / 6502), PPU (2C02), APU, DMA, cartridge formats and mappers, and controllers. One Markdown file per wiki page; links between included pages point at the local files, other links point at the live wiki (not available offline). Images were omitted.

Good starting points: [CPU](nesdev-wiki/CPU.md), [PPU](nesdev-wiki/PPU.md), [APU](nesdev-wiki/APU.md), [Cycle reference chart](nesdev-wiki/Cycle_reference_chart.md), [iNES](nesdev-wiki/INES.md), [Mapper](nesdev-wiki/Mapper.md).
