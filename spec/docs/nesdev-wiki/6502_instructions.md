Below are some references for the 6502 instruction set:

* [Instruction reference](Instruction_reference.md), describing all official instructions and how they function
* [CPU unofficial opcodes](CPU_unofficial_opcodes.md), including a full opcode matrix of all official and unofficial opcodes
* [Programming with unofficial opcodes](https://www.nesdev.org/wiki/Programming_with_unofficial_opcodes)
* [6502 assembly optimisations](https://www.nesdev.org/wiki/6502_assembly_optimisations)
* [Delay code](https://www.nesdev.org/wiki/Delay_code), and [Fixed cycle delay](https://www.nesdev.org/wiki/Fixed_cycle_delay): how to create a delay of a precise number of CPU cycles with smallest number of code bytes
* [6502 cycle times](6502_cycle_times.md)

## External links

* <http://users.telenet.be/kim1-6502/6502/proman.html> - MOS 6502 programming manual
* <http://nesdev.org/6502_cpu.txt> - Includes tick-by-tick breakdowns of instructions (see [CPU interrupts](CPU_interrupts.md) for breakdowns of interrupts)
* <https://www.nesdev.org/obelisk-6502-guide/reference.html> - Historical 6502 instruction reference, but largely obsoleted by NESdev's [instruction reference](Instruction_reference.md)
* [Visual 6502](http://visual6502.org/) can be used to figure out obscure instruction behavior. There's also a [2A03 version](https://www.qmtpro.com/~nes/chipimages/visual2a03/) available (hosted on residential broadband, so avoid needless shift-reloading). There is also [a tutorial on reading the circuit diagrams](https://www.nesdev.org/wiki/Visual_circuit_tutorial) available, aimed at beginners.
